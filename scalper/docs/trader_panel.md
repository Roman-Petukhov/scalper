# Панель «Трендовые пробои»: запуск на VPS

Сервер ищет пробои трендовых линий по закрытиям (правило из `docs/research_report.md`: линия через значимые
вершины, агрессоры >= 55%, тренд старшего ТФ, стоп за свингом, цель 3R) сразу после закрытия свечи каждого
включённого таймфрейма и показывает сигналы в веб-панели. Данные — публичное API фьючерсов Binance (в свечах есть
объём рыночных покупок, на нём стоит фильтр агрессоров). Исполнение на Bybit — этап 2.

## Что умеет панель
- Режим «Ручная / Авто». Ручная: под каждым сигналом «Вхожу» / «Пропустить». Авто: сигналы исполняет бот (этап 2;
  до него сигналы только записываются).
- Кнопки 15m / 1h / 4h — какие сигналы присылать. 15m помечен «без преимущества» (по бэктесту).
- Вход: ретест (по умолчанию, лучше на свежих данных), по рынку или гибрид по длине свечи пробоя.
- Риск на сделку, число позиций, дневной стоп, цель, порог агрессоров — настраиваются и проверяются.
- Кнопки «Скан» — проверить рынок сейчас, не дожидаясь закрытия свечи.
- Уведомления в Telegram с графиком (если заданы токен и chat id).

## Сервер
VPS в Европе с 1–2 ГБ памяти (Hetzner CX22, Contabo VPS S), Ubuntu 24.04, Docker:

```bash
curl -fsSL https://get.docker.com | sh
git clone <репозиторий> && cd scalper/scalper/deploy
cp env.example .env && nano .env          # пароль, секрет сессий, домен, Telegram
docker compose up -d --build
docker compose logs -f trader             # первые сканы — после ближайшего закрытия свечи
```

Домен: A-запись на IP сервера, его же в `DOMAIN` и `PANEL_URL` — сертификат HTTPS Caddy выпустит сам.
Без домена: `DOMAIN=localhost`, вход по `https://<IP>` с предупреждением браузера о сертификате.

Обновление: `git pull && docker compose up -d --build`. База и графики — в томе `trader-data`.

## Безопасность
- Пароль и секрет сессий — только в `deploy/.env` на сервере.
- Сессия в cookie на 14 дней, `SameSite=Strict`, при HTTPS — `Secure`; действия принимаются только из панели
  (заголовок HTMX), неверный пароль задерживает ответ на 1 с.
- Ключи Bybit появятся на этапе 2 и тоже будут только в `.env` (права: торговля, без вывода средств).
