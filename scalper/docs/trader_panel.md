# Панель «Трендовые пробои»: запуск на VPS

Сервер ищет пробои трендовых линий по закрытиям (правило из `docs/research_report.md`: линия через значимые
вершины, агрессоры >= 55%, тренд старшего ТФ, стоп за свингом, цель 3R) сразу после закрытия свечи каждого
включённого таймфрейма и показывает сигналы в веб-панели. Данные — публичное API фьючерсов Binance (в свечах есть
объём рыночных покупок, на нём стоит фильтр агрессоров). Исполнение на Bybit — этап 2.

## Что умеет панель
- Режим «Ручная / Авто». Ручная: под каждым сигналом «Вхожу» / «Пропустить». Авто: сигналы исполняет бот (этап 2;
  до него сигналы только записываются).
- Кнопки 15m / 1h / 4h — какие сигналы присылать; все таймфреймы равноправны и работают по одному правилу.
- Вход: ретест (по умолчанию, лучше на свежих данных), по рынку или гибрид по длине свечи пробоя.
- Риск на сделку, число позиций, дневной стоп, цель, порог агрессоров — настраиваются и проверяются.
- Кнопки «Проверить рынок сейчас» — проверить рынок сейчас, не дожидаясь закрытия свечи.
- Уведомления самого приложения: системные (Windows / macOS / Android) с иконкой панели, звук, счётчик новых
  сигналов на иконке. Включаются кнопкой «Включить уведомления»; приходят, пока окно панели открыто (можно
  свёрнутым). Клик по уведомлению открывает панель на этом сигнале.
- Push-уведомления (Web Push): на телефон и компьютер, даже когда панель закрыта. Включаются той же кнопкой на
  каждом устройстве; «Проверить» отправляет пробное уведомление через сервер.
- Telegram — необязательно, дублирует сигналы с графиком, если заданы токен и chat id.

## Телефон: панель и уведомления, пока сервер на компьютере
Телефону нужен доступ к панели по HTTPS (без него браузер не даёт push). Бесплатно и без открытия в интернет —
Tailscale:
1. Установить Tailscale на компьютер (tailscale.com/download) и на телефон (App Store / Google Play), войти в
   один и тот же аккаунт.
2. В админке Tailscale (login.tailscale.com) → DNS: включить MagicDNS и «HTTPS Certificates → Enable HTTPS».
3. На компьютере в командной строке: `tailscale serve --bg localhost:8000`. Команда покажет адрес вида
   `https://<компьютер>.<сеть>.ts.net` — он открывается только с ваших устройств.
4. На телефоне открыть этот адрес, войти, «Включить уведомления».
   - Android (Chrome): меню → «Добавить на главный экран» — панель как приложение с иконкой.
   - iPhone (iOS 16.4+): Поделиться → «На экран Домой», открыть панель с иконки и только там включить
     уведомления — в обычной вкладке Safari push недоступен.
Уведомления приходят, пока компьютер с панелью включён и не спит.

## Живые графики

Карточка сигнала показывает интерактивный график (TradingView Lightweight Charts, Apache 2.0, логотип TradingView — условие атрибуции): свечи Binance с текущей, трендовая линия, стрелка на свече пробоя, линии входа / стопа / цели (после ордера — цена ордера). Обновляется, пока карточка на экране и вкладка активна: 15m — раз в 5 с, 1h — 10 с, 4h — 15 с. Колесо / щипок — масштаб, перетаскивание — прокрутка. PNG-картинка остаётся запасным вариантом и для уведомлений.

## Торговля на Bybit

1. Bybit → переключиться в **Demo Trading** → профиль → **API** → создать системный ключ: права **Contract — Orders, Positions** (чтение и торговля), **без вывода средств**. Для реального счёта — то же в обычном режиме; лучше с привязкой к IP сервера.
2. Панель → карточка «Биржа»: выбрать «Демо» или «Реальный», вставить API Key и Secret → «Подключить». Панель сначала проверяет ключи запросом баланса и только потом сохраняет их (в базе `data_panel/trader.db` на этом компьютере).
3. Над лентой появится «Кошелёк»: капитал, свободная маржа, нереализованный PnL, результат с 00:00 UTC и открытые позиции со стопом и целью; обновляется каждые 15 с.

Что делает «Вхожу» (и авто-режим на каждом сигнале):
- размер позиции — чтобы стоп стоил «риск на сделку» % капитала; номинал не больше 5 капиталов, плечо на бирже 10× (меньше, если монета не позволяет), объём округляется вниз по шагу монеты;
- ордер ставится сразу со стопом и целью на бирже (`stopLoss` / `takeProfit` Bybit), метка `tt-<id сигнала>` не даёт отправить сигнал дважды;
- вход «рынок» — рыночный ордер; если цена уже ушла так, что до цели меньше 1.5 стопа, или прошла стоп / цель — ордер не отправляется, причина видна на карточке;
- вход «ретест» — лимитка на линии; если не исполнилась за «Лимитка живёт» свечей, панель сама её снимает (проверка раз в минуту);
- отказы по правилам: по монете уже есть позиция или лимитка, открыто «Позиций одновременно», капитал ниже начала дня на «Дневной стоп» %, не хватает маржи, монеты нет на Bybit, объём меньше минимального.

В авто-режиме бот присылает уведомление о каждом входе и каждом отказе. Результат дня считается по изменению капитала с первого замера после 00:00 UTC — ввод и вывод средств в этот день его искажают.

## На своём компьютере (без Docker)
Нужен Python 3.12 (python.org; на Windows при установке отметить «Add python.exe to PATH").

1. Один раз склонировать (нужен Git for Windows с git-scm.com; при первом клонировании откроется вход в GitHub):
   `git clone -b main-t2qdvg https://github.com/Roman-Petukhov/scalper.git %USERPROFILE%\Desktop\scalper-git`
   Дальше `run_panel` при каждом запуске сам делает `git pull` — скачивать архивы больше не нужно.
   (Можно и ZIP: GitHub → ветка `main-t2qdvg` → Code → Download ZIP, но тогда без автообновления.)
2. Открыть папку `scalper` внутри и запустить:
   - Windows: двойной клик по `run_panel.bat`;
   - Mac / Linux: `./run_panel.sh` в терминале.
3. Первый запуск ставит зависимости (2–5 минут) и спрашивает пароль панели. Настройки сохраняются в `panel.env`,
   данные — в `data_panel/` (оба не попадают в git).
4. Браузер откроет `http://127.0.0.1:8000`. Панель доступна только с этого компьютера.

Сигналы приходят, пока компьютер включён и не спит. Остановить — Ctrl+C в окне запуска.

Как приложение:
- Windows: первый запуск `run_panel.bat` кладёт на рабочий стол ярлык «Трендовые пробои» с иконкой. Дальше
  панель запускается с него: сервер стартует в свёрнутом окне, панель открывается отдельным окном (Edge, Chrome
  или Яндекс Браузер) без адресной строки.
- Любая система: в Chrome / Edge меню → «Установить приложение» (или значок установки в адресной строке) —
  иконка появится в «Пуске» / Launchpad. На телефоне (через туннель или VPS) — «На экран Домой».

## Сервер
VPS в Европе с 1–2 ГБ памяти (Hetzner CX22, Contabo VPS S), Ubuntu 24.04, Docker:

```bash
curl -fsSL https://get.docker.com | sh
git clone <репозиторий> && cd scalper/scalper/deploy
cp env.example .env && nano .env          # пароль, секрет сессий, домен, Telegram
docker compose up -d --build
docker compose logs -f trader             # первые сканы — после ближайшего закрытия свечи
```

Домен: A-запись на IP сервера, его же в `DOMAIN` и `PANEL_URL` — сертификат HTTPS Caddy выпустит сам.
Без домена: `DOMAIN=localhost`, вход по `https://<IP>` с предупреждением браузера о сертификате.

Обновление: `git pull && docker compose up -d --build`. База и графики — в томе `trader-data`.

## Безопасность
- Пароль и секрет сессий — только в `deploy/.env` на сервере.
- Сессия в cookie на 14 дней, `SameSite=Strict`, при HTTPS — `Secure`; действия принимаются только из панели
  (заголовок HTMX), неверный пароль задерживает ответ на 1 с.
- Ключи Bybit появятся на этапе 2 и тоже будут только в `.env` (права: торговля, без вывода средств).
