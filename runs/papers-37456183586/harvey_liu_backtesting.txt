          key parameters to make Sharpe ratio adjustments and
          calculate the corresponding haircuts. It has eight inputs

          The first input is the sampling frequency for the return
          series. Five options (daily, weekly, monthly, quarterly, and
          annually) are available.24 The second input is the number of

          input asks if the Sharpe ratio has been corrected for auto-
          correlation.25 The sixth input asks for the autocorrelation
          of the returns if the Sharpe ratio has not been corrected for
          autocorrelation.26 The seventh input is the number of tests
          assumed. Lastly, the eighth input is the assumed average
          level of correlation among strategy returns.
